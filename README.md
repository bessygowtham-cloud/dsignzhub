# Dsignzhub

Marketing site for **[dsignzhub.com](https://www.dsignzhub.com)** — a digital agency offering
web design and development, PWAs, e-commerce, digital marketing, SEO, Google Ads, graphic
design and branding for Indian businesses.

Static HTML/CSS/JS. No framework, no build toolchain, no dependencies — the pages are
generated by a small Python script and served as plain files.

**Live:** https://bessygowtham-cloud.github.io/dsignzhub/

---

## Getting started

Preview locally with the no-cache dev server:

```bash
python3 build/serve.py 4173
```

Then open http://localhost:4173. To view it on your phone, use your machine's LAN IP on the
same Wi-Fi (`ipconfig getifaddr en0` on macOS) — e.g. `http://192.168.1.9:4173`.

> Use `build/serve.py` rather than `python3 -m http.server`. The plain server lets browsers
> heuristically cache CSS, so edits appear to do nothing until a hard refresh.

## Editing content

**All page copy lives in [`build/content.py`](build/content.py).** Edit it there, then rebuild:

```bash
python3 build/build.py
```

> ⚠️ Don't hand-edit the generated `.html` files — the next build overwrites them.

`content.py` holds a `SERVICES` list; each entry drives one full service page plus its nav
entry, footer link, sitemap row and homepage card. Adding a service means adding one dict —
the navigation, internal links and sitemap update themselves.

| Field | Purpose |
|---|---|
| `slug` | URL segment, e.g. `/services/seo-services/` |
| `nav` | Label in menus and cards |
| `title` / `meta` | `<title>` and meta description (keep titles ≤ 60 chars) |
| `h1`, `eyebrow`, `lede`, `intro` | Hero and opening copy |
| `deliverables`, `benefits` | Card grids, as `(heading, body)` tuples |
| `faqs` | `(question, answer)` pairs — also emitted as FAQPage schema |
| `related` | Slugs of related services, for internal linking |

## Layout

```
build/            content.py (copy) · build.py (generator) · serve.py (dev server)
css/style.css     all styles, mobile-first
js/script.js      menu, reveals, FAQ accordion, cursor effects
assets/           logo SVGs (full lockup, icon, one-colour print)
index.html        ← generated
services/…        ← generated (index + 9 service pages)
about/  contact/  ← generated
sitemap.xml  robots.txt   ← generated
```

## SEO

Handled per page by the generator, so it can't drift out of sync:

- Unique `<title>` and meta description; `canonical`; OpenGraph and Twitter tags
- JSON-LD: `Service`, `FAQPage` and `BreadcrumbList` on service pages;
  `Organization` + `WebSite` on the homepage
- One `<h1>` per page, breadcrumbs on inner pages, related-service cross-links
- `sitemap.xml` and `robots.txt` generated from the same page list

CSS and JS URLs carry a content hash (`style.css?v=d515e299`) so a deploy never serves a
stale cached stylesheet.

## Deploying

Pushing to `main` triggers [`.github/workflows/deploy.yml`](.github/workflows/deploy.yml),
which publishes to GitHub Pages.

```bash
python3 build/build.py        # regenerate before committing
git add -A && git commit -m "…" && git push
```

**One-time setup (required before the first successful deploy):** in
**Settings → Pages**, set **Source** to **GitHub Actions**.

This cannot be automated. The workflow's `GITHUB_TOKEN` can publish to Pages but
cannot create the Pages site — `configure-pages` with `enablement: true` fails with
`Resource not accessible by integration`, because creating a site needs repo-admin
rights the default token does not carry. Until the toggle is set, every run fails at
"Setup Pages" with `Get Pages site failed`.

To point the custom domain at it, add a `CNAME` file containing `www.dsignzhub.com` and
set the DNS record at your registrar.

## Accessibility & motion

Skip link, visible focus states, ARIA on the menus and FAQ accordion. Cursor effects,
spotlights and parallax are gated behind `(hover: hover) and (pointer: fine)` and disabled
entirely under `prefers-reduced-motion: reduce`.

## Known gaps

- **Contact form has no backend.** It opens the visitor's mail client via `mailto:`.
  Wire it to Formspree, Web3Forms or a serverless function before launch.
- **Placeholder contact details** — `hello@dsignzhub.com` and `+91 00000 00000` in
  `build/content.py` need replacing with the real ones.
- No blog, case studies or testimonials yet.
